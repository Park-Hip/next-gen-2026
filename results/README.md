# Committed evaluation runs (results/)

The evaluation harness (`src/appota_kb/evaluation/`) writes here and the report reads from here; both are committed so any change to a check or to the report is traceable against the same replies.

| Path | What it is |
|---|---|
| `<run_id>.jsonl` | One JSON record per row of `data/test_cases.yaml`, as `python -m appota_kb.evaluation.run` wrote it (committed; never edited by hand) |
| `<run_id>.review.yaml` | Hiep's reading of the run: `faithful` (answer cards) and `lesson` (every row) |
| `<run_id>.review.md` | The generated review sheet, regenerated by `python -m appota_kb.evaluation.report` |

`run_id` is the Vietnam local time the run started, `YYYYMMDD-HHMM`.
The demo's `/cases` page shows the run that the committed `docs/mission2/test_report.md` names, so a practice run saved here never replaces the official one.
All data here is simulated ("giả lập").
